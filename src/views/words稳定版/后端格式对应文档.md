# 后端 JSON 格式对应文档

本文档详细说明了 Wordsbeat 编辑器导出/保存时生成的 JSON 数据结构，以及对应的参数含义。后端在存储或同步数据时应遵循此格式。

---

## 1. 整体数据结构

编辑器的数据由 **文档内容 (data)** 和 **全局配置 (options)** 两部分组成。在保存完整状态时，建议结构如下：

```js
{
  "main": [ // 【必填】正文内容数组 (IElement[])
    { "value": "标题", "size": 24, "bold": true, "rowFlex": "center" },
    { "value": "\n" }
  ],
  "header": [ // 【可选】页眉内容数组
    { "value": "内部文档", "italic": true }
  ],
  "footer": [ // 【可选】页脚内容数组
    { "value": "第 {pageNo} 页", "rowFlex": "center" }
  ],
  "graffiti": [], // 【可选】涂鸦/手写数据
  "options": { // 【重要】全局配置
    "margins": [100, 120, 100, 120], // 页边距：[上, 右, 下, 左]
    "paperSize": [794, 1123],         // 纸张大小：[宽, 高]
    "paperDirection": "vertical",     // 纸张方向：vertical(纵向), horizontal(横向)
    "watermark": { // 水印相关配置
      "data": "中飞水印",              // 水印文本
      "color": "#f0f0f0",            // 水印颜色
      "size": 30,                    // 字体大小
      "opacity": 0.3,                // 透明度 (0-1)
      "repeat": true                 // 是否重复铺满
    },
    "pageNumber": { // 页码相关配置
      "format": "{pageNo} / {pageCount}", // 显示格式
      "size": 12,                    // 字体大小
      "rowFlex": "center"            // 对齐方式
    }
  }
}
```

---

## 2. 元素属性 (IElement) 详解

### 2.1 基础属性 (Base)
所有元素类都具备或可能挂载以下基础属性，用于标识、类型声名及扩展数据的存储。

| 参数名称 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `id` | `string` | 元素的唯一标识符。 | `"uid-9x3a..."` |
| `type` | `string` | 元素类型，如果不传默认视为普通文本。可选：`text`, `image`, `table`, `hyperlink`, `control`, `pageBreak`, `separator`, `latex`, `checkbox`, `radio`, `date` 等。 | `"text"` |
| `value` | `string` | 元素的核心内容数据。 | 对于文本是 `"汉字"`, 图片为 Base64。 |
| `conceptId` | `string` | 业务概念 ID，极重要，常用于动态渲染和表单字段前后端映射绑定。 | `"doctor_name"` |
| `extension` | `any` | 业务系统自定义的任意扩展字段装载体，原样解析与序列化。 | `{ "source": "HIS" }` |
| `groupIds` | `array` | 用于组合多个元素（如组合成一串不可分割的字符），存放分组的 ID 数组。 | `["group-1"]` |

### 2.2 样式属性 (Style)
适用于需要直接进行文字样式渲染的元素（如文字、日期、部分控件文本等）。

| 参数名称 | 类型 | 说明 | 示例 / 可选值 |
| :--- | :--- | :--- | :--- |
| `font` | `string` | 字体家族 (Font Family)。 | `"Microsoft YaHei"` |
| `size` | `number` | 字号大小 (通常相对像素 px)。 | `16` |
| `bold` | `boolean` | 是否加粗。 | `true` 或 `false` |
| `italic` | `boolean` | 是否斜体。 | `false` |
| `underline` | `boolean` | 是否包含下划线。 | `true` |
| `strikeout` | `boolean` | 是否包含删除线。 | `false` |
| `color` | `string` | 文本颜色 (十六进制格式 Hex)。 | `"#ff0000"` |
| `highlight` | `string` | 文本背景高亮底色 (Hex)。 | `"#ffff00"` |
| `letterSpacing`| `number` | 自定义的字符间距。 | `2` |
| `textDecoration`| `object` | 更详细的装饰线结构：`{ style: "solid" }` (单实线)、`double` (双实线)、`dashed` (虚线)、`wavy` (波浪) | `{"style": "wavy"}` |

### 2.3 排版属性 (Paragraph)
主要影响段落或行级的排版与对齐。

| 参数名称 | 类型 | 说明 | 示例 / 可选值 |
| :--- | :--- | :--- | :--- |
| `rowFlex` | `string` | 行水平对齐方式。 | `left`, `center`, `right`, `alignment` (分散/两端对齐) |
| `rowMargin` | `number` | 段落当前行的行间距倍数。 | `1.5`, `2.0` |
| `spacingBefore`| `number` | 段前间距 (段落开始前)。 | `1.0` |
| `spacingAfter` | `number` | 段后间距 (段落结束后)。 | `0` |
| `indent` | `number` | 缩进大小，通常代表字符倍数。 | `2` (如首行缩进 2 字符) |

## 3. 全局 Options 核心配置

### 3.1 水印 (Watermark)
| 参数 | 说明 |
| :--- | :--- |
| `data` | 水印文字内容 |
| `type` | 水印类型：`text` (默认) 或 `image` |
| `color` | 水印颜色（仅文本水印有效） |
| `opacity` | 透明度 (0 ~ 1) |
| `size` | 字体大小 |
| `repeat` | 是否重复铺满背景 |
| `gap` | 重复时的间距 `[horizontal, vertical]` |
| `font` | 字体家族 |

### 3.2 页码 (PageNumber)
| 参数 | 说明 |
| :--- | :--- |
| `format` | 页码格式（支持 `{pageNo}` 和 `{pageCount}` 占位符） |
| `fromPageNo` | 起始显示的页码 |
| `startPageNo` | 逻辑起始页码数值 |
| `size`, `color`, `font` | 样式配置 |
| `rowFlex` | 对齐方式 |

## 4. 复杂类型详情

### 4.1 表格 (Table)
当 `type` 为 `"table"` 时，元素包含完整的表格描述信息。

| 参数名称 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `tableId` | `string` | 表格的唯一标识符。 | `"tbl_... "` |
| `colgroup` | `array` | 列宽配置数组。对象格式：`{ width: number }` | `[{width: 200}, {width: 200}]` |
| `trList` | `array` | 行数据数组。 | - |
| `trList[i].tdList` | `array` | 该行的单元格列表。 | - |
| `trList[i].trHeight` | `number` | 该行的高度。 | `40` |
| `tdList[j].value` | `array` | **最重要的字段**。单元格内部的内容 (IElement 数组)。 | `[{value: "文字"}]` |
| `tdList[j].colspan` | `number` | 合并列数。 | `1` (不合并) |
| `tdList[j].rowspan` | `number` | 合并行数。 | `1` (不合并) |
| `tdList[j].backgroundColor` | `string` | 单元格背景颜色。 | `"#f5f5f5"` |
| `tdList[j].verticalAlign` | `string` | 垂直对齐方式：`top`, `middle`, `bottom` | `"middle"` |

### 4.2 控件 (Control)
当 `type` 为 `"control"` 时，通常用于表单录入，数据核心在 `control` 对象中。

| 参数名称 | 类型 | 说明 | 可选值/示例 |
| :--- | :--- | :--- | :--- |
| `control.type` | `string` | 控件子类型。 | `text`, `select`, `checkbox`, `radio`, `date`, `number` |
| `control.value` | `array` | 控件当前渲染的元素数组 (IElement[])。 | - |
| `control.placeholder` | `string` | 占位提示文字。 | `"请输入内容"` |
| `control.conceptId` | `string` | 业务关联 ID (如对应数据库字段名)。 | `"patient_name"` |
| `control.prefix` | `string` | 控件前缀。 | `"【"` |
| `control.postfix` | `string` | 控件后缀。 | `"】"` |
| `control.valueSets` | `array` | 选项集合（针对 select/checkbox/radio）。 | `[{value: "男", code: "1"}, {value: "女", code: "2"}]` |

### 4.3 标题 (Title)
当元素具备标题属性或作为标题插入时。

| 参数名称 | 类型 | 说明 | 可选值 |
| :--- | :--- | :--- | :--- |
| `level` | `string` | **标题级别**，影响目录生成。 | `first`, `second`, `third`, `fourth`, `fifth`, `sixth` |
| `titleId` | `string` | 标题组唯一 ID。 | - |

### 4.4 其他常见复杂类型

#### 单选/复选框 (Checkbox/Radio)
`type` 为 `"checkbox"` 或 `"radio"`。在公文和表单系统中广泛使用。
*   `checkbox.value` / `radio.value`: (Boolean) 当前是否被选中， `true` (选中) 或 `false` (未选中)。
*   `checkbox.code` / `radio.code`: (String) 用于对应后端数据库或者表单字典的标识码。
*   `checkbox.disabled` / `radio.disabled`: (Boolean) 限制状态：是否被置灰不可点击。

#### 超链接 (Hyperlink)
`type` 为 `"hyperlink"`。
*   `url`: (String) 跳转的目标链接地址。
*   `hyperlinkId`: (String) 超链接标识符。
*   `valueList`: (Array) 链接包装的子元素数组 (展示的文字形式依然是 IElement 结构)。

#### 日期 (Date)
`type` 为 `"date"`。常用于快捷落款和标准发文日期。
*   `dateFormat`: (String) 日期的格式化映射规则，如 `"yyyy-MM-dd"` 或 `"yyyy-MM-dd hh:mm:ss"`。
*   `dateId`: (String) 日期元素编组的唯一 ID。

---

## 5. 交互流程说明


1.  **保存 (Save)**: 后端接口应接收上述结构的 JSON 并存入数据库。
2.  **加载 (Load)**: 前端从接口拿到 JSON 后，直接调用 `instance.command.executeSetValue(json)`。
