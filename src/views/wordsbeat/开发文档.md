# Wordsbeat 核心编辑器开发调试文档

由于团队已将排版引擎源码全量迁入并魔改（`src/views/wordsbeat/canvas-editor`），本项目不再依赖和使用外部现成的富文本 npm 包。
为了让前端研发同事能有一份**完全替代官方文档的内部参考手册**，本文档依照完整的特性大纲，梳理了引擎暴露的核心 API 及使用规则。

---

## 1. 快速入门与实例获取

全局只有一个核心的 `Editor` 实例，在 `index.vue` 的 `onMounted` 生命周期中被实例化。
为了方便各种组件之间的跨越调用以及控制台调试，此实例被全局挂载：

```typescript
// 控制台全局变量，可直接在 Chrome Devtools 输入此变量调试
window.__CANVAS_EDITOR_INSTANCE__ 
window.editor
```
所有针对画布的操作，都必须依赖这个 `instance` 对象及其子模块。

---

## 2. 命令 (Command)

核心操作层，主要分为**修改画布的动作命令**和**读取状态的数据命令**。所有的命令都在 `instance.command` 命名空间下。

### 2.1 执行动作命令 (Execute)

此类命令会直接修改编辑器的排版或内容边界，触发界面重绘。
默认情况下，这些命令作用于**当前鼠标所选中的文本选区**；如果没有选区，则作用于光标此刻所在的**段落**。

```typescript
// --- 撤销与重做 ---
instance.command.executeUndo(); 
instance.command.executeRedo();

// --- 字体格式设定 ---
instance.command.executeSize(16);          // 设定字号 (数值代表px)
instance.command.executeSizeAdd();         // 字号+1
instance.command.executeSizeMinus();       // 字号-1
instance.command.executeFont('方正小标宋_GBK, 黑体'); // 设定字体族

// --- 字体装饰 ---
instance.command.executeBold();            // 切换加粗
instance.command.executeItalic();          // 切换斜体
instance.command.executeStrikeout();       // 切换删除线
instance.command.executeSuperscript();     // 切换上标
instance.command.executeSubscript();       // 切换下标
instance.command.executeUnderline({ style: 'solid' }); // 设定下划线及其样式

// --- 颜色处理 ---
instance.command.executeColor('#FF0000');     // 改变字体颜色
instance.command.executeHighlight('#FFFF00'); // 改变背景高亮颜色

// --- 段落排版 ---
// 行对齐：'left' | 'center' | 'right' | 'alignment' (两端对齐) | 'justify' (分散对齐)
instance.command.executeRowFlex('center'); 
instance.command.executeRowMargin(1.5);       // 倍数逻辑行间距
instance.command.executeList(listType, listStyle); // 列表转换

// --- 万能插入 (核心功能) ---
// 用于将任何文字、对象、私有拓展字段动态打入文档流
instance.command.executeInsertElementList([
  { value: '特急', size: 16, bold: true, color: '#ff0000' },
  { 
    type: 'image', // 插入图片或 SVG
    value: 'data:image/svg+xml;base64,.....', 
    width: 600, height: 6 
  }
]);

// 插入表格、超链接和分页符
instance.command.executeInsertTable(3, 4); // 3行4列
instance.command.executeHyperlink({ url: 'http://', valueList: [{value: '点击'}] });
instance.command.executePageBreak();
```

### 2.2 获取数据命令 (Get)

当在业务侧（Vue 组件）需要提取编辑器的内部状态时，应使用获取型指令：

```typescript
// 1. 获取包含页眉、页脚全貌的底层渲染树（持久化保存的唯一标准对象）
const docData = instance.command.getValue(); 

// 2. 获取去除了标签信息的纯净无格式文本，常用于"摘要"生成或"文字搜索"
const plainTextMap = instance.command.getText();

// 3. 获取光标目前框选的文本字符
const selectionText = instance.command.getRangeText();

// 4. 读取当前的配置项参数
const options = instance.command.getOptions();
```

## 3. 监听 (Listener)

为了实现类似 Word 的沉浸式交互菜单（当鼠标点到粗体字上，工具栏的加粗按钮会自动激活反馈色），需要建立监听机制机制。

```typescript
// ① 内容变动监听
// 非常高频的勾子，切记需加以防抖 debounce 处理
instance.listener.contentChange = debounce(async () => {
    // 处理更新字数统计等
    const count = await instance.command.getWordCount();
    // 或执行 IndexedDB 自动保存草稿
}, 1000);

// ② 范围/光标属性移动监听 (Ribbon UI 状态同步核心)
instance.listener.rangeStyleChange = (payload) => {
    // 点击加粗文字、或新拉选区时触发
    if (payload.bold) {
        // ...高亮粗体按钮
    }
    // ...同样可检测 payload.font, payload.size, payload.rowFlex 等。
};

// ③ 可视分页监听
// 用于反馈到底部状态栏显示 "您正在浏览第几页"
instance.listener.visiblePageNoListChange = (payload) => {
    // 连页模式下可能是多个：[0, 1]
    console.log(`当前屏幕可见页: ${payload.map(i => i + 1)}`);
};
```

## 4. 快捷键 (Shortcut)

引用的内核自带了大量排版习惯快捷键（如 `Ctrl+Z`, `Ctrl+B`, `Ctrl+S` 等）。如果需要拓展系统级快捷热键：

```typescript
// 自定义快捷键注册
instance.register.shortcutList([
  {
    key: 'S',        // 按键名称
    ctrl: true,      // 需同时按 Ctrl
    shift: true,     // 需同时按 Shift
    isBypass: false, // 阻止默认浏览器行为
    callback: (command) => {
      console.log('触发了 Ctrl + Shift + S');
      // 这里可以调用 command API 执行自定义逻辑
    }
  }
]);
```

## 5. 右键菜单 (Context Menu)

编辑器本身禁止了浏览器的原生右键事件，实现了属于渲染引擎内部的右键控制链。
你可以在业务初始化阶段，向引擎注册你需要的**自定义右键菜单项**（例如我们在 `index.vue` 做的“新增批注”功能）：

```typescript
instance.register.contextMenuList([
  {
    name: '新增批注',  // 显示名称
    icon: 'comment',  // 预置图标或 SVG DOM 字符串
    // 判断该菜单在何时才显示 (when)
    when: (payload) => {
      // payload 内置当前光标状态：是否在只读模式、是否有选区、所处区间
      return (!payload.isReadonly && payload.editorHasSelection && payload.zone === 'main');
    },
    // 点击回调
    callback: (command) => {
      // 业务逻辑处理，如弹个窗，随后打组
      const groupId = command.executeSetGroup();
      console.log(`为选中文字生成了讨论组 ID: ${groupId}`);
    }
  }
]);
```

## 6. API (全局设置相关)

除了操作画布，还可以从宏观上更改编辑器的运作设置。

### 6.1 实例级数据强制替换
```typescript
// 此方法极其强大，它会抹除目前全部画布的渲染图树，直接恢复并重绘出你传入的内容和配置。
// 常用于：文档回显、一键替换公文模版。
instance.command.executeSetValue({
  main: [
    { value: '标题', size: 36, rowFlex: 'center' }
  ],
  header: []
});
```

### 6.2 动态更新全局属性
不需要重新销毁并实例化 Editor，可以通过 API 直接在线更新系统配置：
```typescript
// 动态修改配置选项：例如在线改页面大小和水印等
instance.command.executeUpdateOptions({
   pageMode: 'paging', // 切换到分页模式
   watermark: {
       data: '中飞机密文件',
       color: '#f0f0f0',
       size: 30,
       opacity: 0.8
   }
});
```

## 7. 公文特化与黑科技实现解密

### 7.1 DOCX 无损转化接驳口 (`utils/docxImporter.ts`)
由于标准 `Mammoth.js` 的做法是先转 HTML 再由系统清洗，这在公文中是**不可容忍**的，会直接丢失“方正小标宋”等明确字号规范及行高体系。我们在 `utils` 层做了 AST 的拦截，将其**直接翻译为我们底层的 `IElement[]` 结构**。导出同理，`docxExporter` 负责将画布直接塞回 xml 压缩包。

### 7.2 红线引擎与间距覆盖
- **红线渲染**：由于不能依赖 HTML `<hr>` 解决居中及不同机器渲染不均的问题，直接在执行 `executeInsertElementList` 时构建了超宽的 SVG Base64 当成图片强行塞入画布中心并包裹 `\n`。
- **段起段后距设定**：利用 `instance.command.executeUpdateElementById`，扫描鼠标所在行的第一个节点，找到 ID 之后无视命令总线的限制强行赋予 `spacingBefore`。首行缩进功能亦同理，我们使用了注入 `\u3000` (全角空格) 并在 extension 追加特征参数来实现。

## 8. 开发环境调试利器 (DevTools)

这是最重要的部分：鉴于数据流变成了 Canvas 计算点阵结构，如果你遇到排版对不齐或者对象拿不到参数的情况，**不要用 F12 `Elements` 看 HTML**，因为全是 Canvas，没用的。

推荐安装官方的浏览器扩展工具（Chrome Extension）。由于我们在 `index.vue` 已把 `instance` 指定给了 `window.__CANVAS_EDITOR_INSTANCE__`，插件在我们环境内可以做到**直接关联使用**：

1. **下载**: [https://github.com/Hufe921/canvas-editor-devtools](https://github.com/Hufe921/canvas-editor-devtools) （以“加载已解压的扩展程序”形式放到开发者模式里）
2. **使用**: 启动我们的 `npm run dev`，F12 切到 `Canvas Editor` 标签卡。
3. **能力**:
   - 右侧会立刻出现**元素树检查器**，点击画布的字就能立即在控制台看到它的排版参数、缩进量等所有内部结构信息。
   - **事件监控台**能拦截键盘与鼠标所有的内部钩子，排查“焦点丢失”、“光标错动”的不二法门。
